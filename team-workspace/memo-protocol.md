# RAGY Memo Protocol

## Standard Format
[FROM] -> [TO] | [STATUS] | [SUBJECT]
[CONTENT]

## Roles
- Dev: Raggy-Developer
- QA: Raggy-QA
- GM: Ragy-Orchestrator

## Current Office Workflow
1. GM assigns task to Dev.
2. Dev writes code and sends Memo to QA.
3. QA reviews and sends Memo to GM (Success or Change Request).
4. GM notifies User (You).
